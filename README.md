# DesAlexG · Портфолио лендингов и веб-интерфейсов

Статический сайт-портфолио на чистом HTML, CSS и JavaScript — без тяжёлых сборщиков, сторонних фреймворков и ежемесячных подписок на конструкторы. Все пути относительные, поэтому сайт корректно работает как на собственном домене, так и на **GitHub Pages**.

## Структура проекта

- `index.html` — главная страница портфолио с интерактивными превью сайтов, этапами работы, тарифами и калькулятором оценки.
- `demos/01-detailing/` — **BLACKLINE Detailing**: лендинг автодетейлинга со схемой зон кузова и слайдером «До / После».
- `demos/02-finance-b2b/` — **СчётПро**: B2B-бухгалтерия с калькулятором тарифа в ₽/мес и тестом налоговых рисков.
- `demos/03-loft-studio/` — **MATERIA**: мастерская лофт-мебели с интерактивным фото-шоурумом интерьеров и каталогом.
- `demos/04-edtech-platform/` — **КАМПУС**: EdTech-платформа для онлайн-школ с каруселью экранов, bento-сеткой и FAQ.
- `assets/` — локальные оптимизированные изображения.

## Быстрый запуск на GitHub Pages

1. Создайте пустой публичный репозиторий на GitHub (например, `portfolio`).
2. Загрузите код из этой папки:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
3. Откройте на GitHub: **Settings → Pages → Build and deployment → Branch: `main` / `/ (root)` → Save**.
4. Через ~1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
